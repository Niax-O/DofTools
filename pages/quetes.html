Quêtes & succès

Organiser ta progression et trouver de l’aide rapidement quand une étape bloque.

Comment faire ?

1

Ajoute ton objectif

Utilise /objectifs pour noter la quête ou le succès que tu veux terminer.

2

Identifie le blocage

Indique clairement l’étape, le combat ou le besoin de joueurs.

3

Crée un groupe

Si nécessaire, utilise /groupe et choisis Quête ou Succès.

Suivre sa progression

Les objectifs personnels servent de repère simple pour conserver les contenus en cours sans devoir les rechercher dans plusieurs salons.

Exemple/objectifs → ajouter « Terminer la quête actuelle » → marquer l’objectif terminé une fois fini.

Trouver de l’aide

Pour une étape nécessitant plusieurs joueurs, /groupe permet de publier une recherche structurée plutôt qu’un message perdu dans le chat.

Astuce Précise l’étape exacte et le nombre de places disponibles. Les autres joueurs comprennent immédiatement si leur aide correspond.

Conseil personnalisé

/conseil peut proposer une prochaine action selon les informations de progression disponibles dans DOFTOOLS.

À retenir Le wiki décrit uniquement les données que DOFTOOLS connaît réellement ; il ne prétend pas suivre automatiquement toute la progression du jeu.
